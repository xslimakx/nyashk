Nyashk Launcher

One app to install and update all our VST3 plugins. Pick a version, read what’s new, update everything in one click.

Windows macOS Linux

Free · open source · unzip and run · GitHub

I

Everything in one place

Every plugin by category, with the installed and the latest version side by side.

II

One-click updates

Update one plugin, the ticked ones or all at once. Downloads are checked with SHA-256.

III

Any version

Pick any release from the dropdown to install or roll back, with release notes since your version.

IV

Stays fresh

Checks in the background, sends a desktop notification and updates itself.

VST3Plugins inside

The launcher installs these. Free and open source, written in Rust.

Synth

NyashkSynth

Serum-style wavetable synth: 3 oscillators, a wavetable editor, two filters, 8 LFOs, a mod matrix, an effect rack and 146 presets.

Manual download GitHub

Autotune

NyashkTune

Realtime vocal pitch correction — from natural tuning to hard T-Pain. Formant shift, harmony voices, follows MIDI.

Manual download GitHub

Compressor

NyashkOpto

LA-2A style optical compressor with program-dependent attack, a limit mode and analog character.

Manual download GitHub

Channel strip

NyashkChannel

SSL-style channel strip: input stage, filters, expander / gate, compressor and a 4-band EQ in one plugin.

Manual download GitHub

Equalizer

NyashkEQ

4-band parametric EQ with HP / LP, draggable nodes over a live spectrum and mid / side mode.

Manual download GitHub

Exciter

NyashkAir

Air and presence for vocals and mixes: MID AIR and HIGH AIR with dynamic reduction, so the top stays smooth.

Manual download GitHub

Preamp

NyashkPre

Light vocal preamp and saturator with tube, iron and clean character plus a simple tone section.

Manual download GitHub

Meter

NyashkMeter

Master-bus analyser: LUFS, LRA, true peak, spectrum, stereo and tonal balance. Audio passes untouched.

Manual download GitHub
