# nyashk.com

Статичний сайт nyashk.com на GitHub Pages. Домен — у файлі `CNAME`.

- Сторінки: `index.html` (англійська), `uk/.../index.html` (українська) — `/`, `community/`, `gallery/`, `launcher/`
- Плагіни на сторінці лаунчера — блоки `<article class="plugin ...">` у `launcher/index.html` і `uk/launcher/index.html`
- Картинки: `photos/` (плагіни — `photos/vst/`, лаунчер — `photos/launcher/`)
- Стилі й скрипти: `styles.css`, `script.js`

Зміни пушиш у `main` — за хвилину вони на сайті.
