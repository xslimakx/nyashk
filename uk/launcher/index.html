Nyashk Launcher

Один застосунок, щоб ставити й оновлювати всі наші VST3-плагіни. Обираєш версію, читаєш що нового, оновлюєш усе одним кліком.

Windows macOS Linux

Безкоштовно · відкритий код · розпакуй і запускай · GitHub

I

Усе в одному місці

Усі плагіни за категоріями — встановлена й остання версія поруч.

II

Оновлення в один клік

Онови один плагін, позначені або всі разом. Завантаження перевіряються SHA-256.

III

Будь-яка версія

Обери будь-який реліз зі списку, щоб встановити чи відкотитись, — з нотатками змін від твоєї версії.

IV

Завжди свіжий

Перевіряє оновлення у фоні, надсилає сповіщення й оновлює сам себе.

VST3Що всередині

Ці плагіни ставить лаунчер. Безкоштовні, з відкритим кодом, написані на Rust.

Синтезатор

NyashkSynth

Wavetable-синтезатор у стилі Serum: 3 осцилятори, редактор хвиль, два фільтри, 8 LFO, мод-матриця, рек ефектів і 146 пресетів.

Завантажити вручну GitHub

Автотюн

NyashkTune

Корекція висоти вокалу в реальному часі — від природного підтягування до жорсткого T-Pain. Зсув формант, голоси-гармонії, слухає MIDI.

Завантажити вручну GitHub

Компресор

NyashkOpto

Оптичний компресор у дусі LA-2A: атака залежить від сигналу, є режим лімітера й аналоговий характер.

Завантажити вручну GitHub

Канальна лінійка

NyashkChannel

Канальна лінійка в стилі SSL: вхід, фільтри, експандер / гейт, компресор і 4-смуговий EQ в одному плагіні.

Завантажити вручну GitHub

Еквалайзер

NyashkEQ

4-смуговий параметричний EQ з HP / LP, точками, що тягаються поверх живого спектра, і режимом mid / side.

Завантажити вручну GitHub

Ексайтер

NyashkAir

Повітря й присутність для вокалу та міксу: MID AIR і HIGH AIR з динамічним приглушенням, щоб верх не різав.

Завантажити вручну GitHub

Преамп

NyashkPre

Легкий вокальний преамп і сатуратор: лампа, трансформатор або чистий звук, плюс проста секція тембру.

Завантажити вручну GitHub

Метр

NyashkMeter

Аналізатор для мастер-шини: LUFS, LRA, true peak, спектр, стерео й тональний баланс. Звук не змінює.

Завантажити вручну GitHub
